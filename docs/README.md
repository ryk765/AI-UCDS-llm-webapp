## 文書の読み進め方

1. システム全体を把握する: `01-system-overview-spec.md`
2. 要件と制約を確認する: `04-requirements-srs.md`
3. 実装構成を確認する: `05-design-hld-lld.md`
4. 画面・利用手順を確認する: `06-ui-use-cases.md`
5. API契約を確認する: `03-api-spec.md`
6. 図だけ参照する: `07-mermaid-architecture.md`

> APIや画面仕様はサブモジュールの実装確認範囲に基づきます。ソース更新後は仕様との整合性を再確認してください。
